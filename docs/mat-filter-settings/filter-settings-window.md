# Filter Settings Window

## About

The Filter Settings window allows the user to create Custom Filters, Add Price
Moves, Define Symbol Sets, establish Conditions, Input Advanced Queries, Set
Result Preferences, and view Filter Results.

*(screenshot: FS about.jpg)*

## Accessing

To access the Filter Settings window, right-click on the MAT window and select
**Edit Filter**.

*(screenshot: Mat rc rdit filter.jpg)*

## Applying a Filter

To apply a filter to a MAT window, click the filter dropdown menu and select the
filter. Click **Apply** to save.

*(screenshot: apply filter.jpg)*

## Add a New Filter

To add a new filter, click the **+** icon. Name the new filter and add a
description. Click **Apply** to save.

*(screenshot: add new filter.jpg)*

## Sections

### Add Price Moves

Configure the selected filter's Time Frame, Minimum Volume Percent, Odd Lots
setting, Price Ranges, Primary/Secondary Moves, and Move Volumes.
See [Add Price Moves (MAT)](add-price-moves.md).

*(screenshot: add price moves about.jpg)*

### Define Symbol Set

Filter by Exchanges, Product Types, and Symbols.
See [Define Symbol Set (MAT)](define-symbol-set.md).

*(screenshot: mat define.jpg)*

### Conditions

Filter MAT window symbols using market metrics, including Price Range, Average
Volume, Market Capitalization, Shares Outstanding, and other key parameters.
See [Conditions (MAT)](conditions.md).

*(screenshot: mat conditions.jpg)*

### Input Advanced Queries

Add custom expressions to the selected MAT filter.
See [Input Advanced Queries (MAT)](input-advanced-queries.md).

*(screenshot: adv que.jpg)*

### Set Results Preferences

Customize how results appear in the MAT window and configure personalized
notifications. See [Set Results Preferences (MAT)](set-results-preferences.md).

*(screenshot: set results pref about.jpg)*

### Filter Results

Filter Results displays the count of symbols that meet the filter criteria.

*(screenshot: filter results.jpg)*
